# 源码阅读入口

本目录解释 tio-boot 的启动、请求分发和底层网络实现。应用开发先阅读入门与 Web 章节；排查初始化顺序、路由优先级或请求生命周期时再进入本目录。

## 阅读顺序

1. [启动与关闭生命周期](<./03.md>)：`TioApplication` 如何创建上下文，配置何时执行，资源如何关闭。
2. [HTTP 请求分发与路由优先级](<./04.md>)：上下文路径、拦截器、Handler、Controller 和静态资源。
3. [TioBootServerHandler](<./06.md>)：网络协议处理入口。
4. [ByteBuffer 分配与回收](<./05.md>)：底层缓冲区行为。

本次源码核对使用 `t-io/tio-boot/src/main/java/nexus/io/tio/boot`，核心类为 `TioApplication`、`context/TioApplicationContext`、`http/handler/internal/TioBootHttpRequestDispatcher`。这是本地检出源码的行为说明，不代表所有历史发布版本完全相同。

文档中仍有历史依赖与包名示例。阅读源码时先对齐业务项目的 Maven 依赖版本、源码检出版本及 `nexus.io` 包名，不能仅替换版本号就认定旧示例兼容。接口文档相关内容见 [Swagger](<./02.md>)；手动注册 Handler 的项目还需检查它是否被文档生成器覆盖。
