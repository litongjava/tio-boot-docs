# 命令清单

本文按功能分组列出当前工程的**全部 122 个方法**，用于快速定位「这件事该用哪个方法」。这是方法名与用途索引，不是每条命令的完整参数手册。参数以源码 `CommandTable` 的注册及服务实现为准，使用说明位于 `.agents/skills/deepseek-browser-use/SKILL.md` 及其 `references/` 分册。

完整实现教程从 [14：公共执行链](./14.md) 开始，后续按功能覆盖本表全部命令，并列出注册参数和 Java 入口。

随时可以用 `list_methods` 或 `GET /playwright/methods` 取到同一份清单，不必靠猜；方法名写错时服务会顺带给近似建议（例如「不支持的方法：list_tabs，你是不是想用 get_tabs / new_tab？」）。

[[toc]]

> 除本文列出的 122 个方法外，还有一个批量入口 `commands`：它不出现在方法清单里，由分发层直接处理，可以一次提交多个方法。见 [04](./04.md) 第四节。

## 十五、网络（5）

| 方法 | 用途 |
| --- | --- |
| `route` / `unroute` | 请求拦截与解除（阻止、放行或模拟响应） |
| `get_requests` | 请求元数据列表（requestId、URL、方法、状态、耗时、failure，有请求体时附 `postData`） |
| `wait_for_response` | 等某个响应到达 |
| `get_response_body` | 按 `requestId` 取响应体 |

**同一个 URL 被重复请求时，用 `requestId` 精确匹配**，否则可能把上一次的响应当成本次结果。请求体与响应体都可能被截断，必须检查 `postDataTruncated` / `truncated` 这类标记。

## 十六、页面读取与差异（9）

| 方法 | 用途 |
| --- | --- |
| `get_page_snapshot` | 页面快照（可选带控制台信息） |
| `diff_dom_text` | 重新做一次快照并与上一次按行做差集，判断「页面到底动没动」比重新读整页省 |
| `get_interactive_map` | 可交互元素映射 |
| `get_form_state` | 表单**实时**状态：`value`、`checked`、`selected`、`readonly` / `disabled` / `editable`，密码值脱敏 |
| `extract_structured_data` | 读取页面正文并可附链接；query 不会触发大模型抽取。回执带 `length`/`truncated`/`limit` |
| `extract_markdown` | 页面（或选择器命中的元素）转 Markdown，**表格按 GFM 表格输出**；命中多个用 `nth` 指定；见 [17](./17.md) |
| `find_text` | 在页面文本里找词或正则，只回**命中 + 前后文 + 行号**；想找一行时用它，别把整页拉回上下文 |
| `list_tables` | 列出页面上所有表格（行列数、class、预览、是否含图），并给出可直接填进 `extract_markdown` 的选择器 |
| `download_image` | 把页面上的图片**原始文件**存到服务端（`data/<id>/`），回 `path`/`url`/`size`/`sha256`；`path` 可直接交给 `ocr_image` |

## 二十一、人机协作（4）

| 方法 | 用途 |
| --- | --- |
| `request_human_input` | 创建求助请求，可带元素 `index` / `selector` 取验证图片 |
| `ask_user` | **向用户要一个值**（银行卡号 / 身份证号 / 验证码），或让他在选项里挑；不截图、不抢焦点，形态与宿主侧的同名提问工具一致 |
| `get_human_input` | 查询请求状态与用户答复 |
| `submit_human_input` | 由宿主或用户提交答复（按 `stepId` / 问题的 `id` 逐条回填，多选题的值给数组） |

`request_human_input` **只是创建请求记录**，接口成功不等于用户已经收到通知 —— 宿主必须真的把求助信息展示出来。见 [04](./04.md) 第五节。
「请人去页面上做一件事」与「向用户要一个值」是两件事：前者用 `request_human_input`，后者用 `ask_user`，参数形态与答复结构见 [25](./25.md)。

## 二十三、按场景查方法

| 想做的事 | 用哪些 |
| --- | --- |
| 看页面有什么、能点什么 | `get_browser_state`（读 `data.text`），必要时 `get_interactive_map` |
| 快照里找不到某元素 | 先看 `pixels_above` / `pixels_below`，再按 [06](./06.md) 第八节处理 |
| 异步表格点完读不到新数据 | `wait_for_stable` 或 `wait_for_count` |
| 原生点击点不动 | 先检查遮挡及页面状态，避免重复提交；模式选择见[点击排障](./08.md) |
| 元素只读 / 被禁用 | 属页面语义，换控件用，别重试（见 [04](./04.md) 错误码表） |
| 页面被弹窗挡住 | `get_modals` 确认当前弹窗，先完成必要验证；仅关闭确实需要关闭的弹窗 |
| 需要 cookie / 登录态 | `get_cookies` / `set_cookie`；跨任务复用靠 profile（见 [05](./05.md)） |
| 要跨域 iframe 里的内容 | `list_frames` 定位 frame，再在 `execute_js` 里带 `frame` |
| 要读页面上的表格（数字别配错列） | `extract_markdown`（表格转 GFM 表格）；只要某张表就传 `selector` |
| 要弄清页面到底动没动 | `diff_dom_text` |
| 遇到验证码 / 登录 | `request_human_input`（见 [04](./04.md) 第五节） |
