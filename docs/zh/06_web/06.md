# 返回文本数据

使用 `Resps.txt` 返回纯文本，由框架设置 `text/plain` 和对应的 charset，无需手写 Content-Type。

```java
import nexus.io.tio.boot.http.TioRequestContext;
import nexus.io.tio.http.common.HttpRequest;
import nexus.io.tio.http.common.HttpResponse;
import nexus.io.tio.http.server.util.Resps;

public class TextHandler {
  public HttpResponse handle(HttpRequest request) {
    HttpResponse response = TioRequestContext.getResponse().setStatus(200);
    return Resps.txt(response, "服务正常", "UTF-8");
  }
}
```

`Resps.txt(response, body, "UTF-8")` 复用传入的响应对象，保留已设置的状态码及其他响应头，使用 UTF-8 编码正文并设置纯文本 Content-Type。第三方协议要求纯文本回执时，可以直接用它返回协议规定的字符串。

| 调用 | 行为 |
| --- | --- |
| `Resps.txt(request, body)` | 创建响应，使用请求字符集 |
| `Resps.txt(response, body)` | 复用响应，使用响应字符集 |
| `Resps.txt(request, body, charset)` | 创建响应，显式指定正文编码与 Content-Type 字符集 |
| `Resps.txt(response, body, charset)` | 复用响应，显式指定正文编码与 Content-Type 字符集 |

普通业务接口需要统一 JSON 响应结构时，继续使用 `RespBodyVo`；纯文本接口根据协议返回原文。
