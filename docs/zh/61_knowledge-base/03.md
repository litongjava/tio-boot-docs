# 模型管理

[[toc]]

Java MaxKB 通过数据库管理平台目录与用户模型，复用官方模型创建、编辑和选择界面。运行时不再从 `api_provider.json`、供应商模型 JSON 或表单 JSON 加载模型配置。

## 三层配置

- `max_kb_model_provider`：平台、默认地址、凭据和参数表单。
- `max_kb_model_catalog`：可选基础模型 ID、类型与启用状态。
- `max_kb_model`：用户创建的模型实例、权限及凭据。

界面的“基础模型”支持输入任意有效模型 ID 后按回车。保存时使用该 ID 实际校验，不替换成固定测试模型；生成请求交给 `UniChatClient`。公有模型可供其他用户选择，私有模型仅所属用户及管理员管理。详情隐藏 API Key，换域名时必须提供新平台的密钥。

## 配置流程

1. 执行数据库初始化与模型目录迁移。
2. 登录后进入“系统 → 模型 → 添加模型”。
3. 选择兼容平台、模型类型和基础模型，输入 API 地址及 Key。
4. 保存通过连接校验后，在应用中选择聊天模型，或创建知识库时选择向量模型。

支持 OpenAI 兼容厂商服务与中转，Claude 等模型可通过兼容中转使用。当前向量存储为 1024 维，已有知识库切换向量空间需要新建知识库并重新导入文档。

完整表结构说明、平台地址、目录刷新接口、自定义模型 ID、迁移与验证见[数据库模型目录、平台接入与自定义模型 ID](35.md)。
