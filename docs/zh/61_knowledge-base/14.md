# 多轮对话问答

一次提问可以触发多个检索轮次：读取当前会话历史 → 改写独立问题 → 检索 → 判断资料是否足够 → 按缺口补充检索 → 最终回答。默认最多 3 轮，配置范围最多 6 轮；充分、无新增证据或达到上限时停止，缺失事实不编造。

会话历史从数据库读取，隔离到当前应用及会话。只有历史 token 超过预算才压缩；轮数超出保留目标不会单独触发摘要。压缩后保留近期原文及持久摘要，摘要生成失败时不推进压缩水位。

最终回答使用应用选择的数据库模型，通过 `UniChatClient.streamOpenAi` 返回 SSE。问题改写、证据核验和摘要使用配置的 Gitee 辅助模型。页面展示检索进度，只有实际超阈值压缩时展示 Compacting context。

完整参数、历史读取、压缩接口、取消与隔离 Python 执行见[32](32.md)。模型配置见[35](35.md)。
