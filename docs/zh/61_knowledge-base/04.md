# 知识库管理

知识库保存名称、说明、所属用户以及选择的向量模型。官方前端通过 `/api/dataset` 完成列表与创建，通过 `/api/dataset/{id}` 获取、修改和删除；后端检查资源归属。

创建时选择可使用的 `EMBEDDING` 模型。默认采用 Gitee 的 `Qwen3-Embedding-8B`，也可使用其他能返回 1024 维向量的兼容模型。不同知识库可以采用不同模型；同一知识库的文档和查询必须采用同一向量空间。

已有分段时禁止直接切换向量模型。要更换模型，创建新的知识库并重新导入文档，避免把旧文档向量与新查询向量比较。私有模型仅所属用户可选择，公共模型可共享使用。

文档先预览解析结果，再提交带文件 ID 的确认分段。知识库列表、文档操作、命中测试及应用关联都检查权限。模型配置见[35](35.md)，文档处理见[29](29.md)。
