# 向量、关键词与混合检索

`MaxKbParagraphRetrieveService` 按指定知识库返回可用分段，过滤已删除、停用的文档和片段。

- `embedding`：使用 `1 - cosine_distance` 作为相似度。多个知识库按各自的模型生成查询向量，再合并候选。
- `keywords`：使用 `pg_trgm` 的 `word_similarity`，不调用向量接口。
- `blend`：向量相似度与关键词得分相加。

接口支持阈值和结果数。结果数限制在 1 至 50，默认 10；相同得分用片段 ID 确定顺序。混合得分不能直接套用纯向量模式的阈值，不同模型的分数分布也应通过样本校准。

问答场景在此单次检索能力上执行证据核验和多次补充检索，停止条件与结果聚合见[迭代检索](32.md)。命中测试用于观察检索片段，不自动等同于完整答案质量评测。
