# 对话日志

[[toc]]

## 当前实现与接口说明

会话与问答记录保存在数据库，完成回答后再发送流结束事件，让紧接着的追问能够读取上一轮内容。查看历史时检查应用和会话归属，分享访客不能读取其他会话。

日志中保存本轮检索资料、检索轮次和停止原因等执行信息；历史摘要单独持久化，原问答不因压缩而直接删除。摘要用于理解语境，检索到的文档才作为当前回答的事实依据。

历史读取、分页、摘要及 token 阈值见[迭代检索与上下文](32.md)。UI 验证记录见[31](31.md)。

## 查看一条问答记录

```http
GET /api/application/{applicationId}/chat/{chatId}/chat_record/{recordId}
Authorization: Bearer <JWT_TOKEN>
```

管理账号和分享访客均需通过应用与会话归属检查。返回记录用于显示回答和检索依据；上下文压缩不会直接删除原问答。历史分页与压缩接口见第 32 章。
