# 用户登录与会话认证

用户通过 `POST /api/user/login` 提交 `username` 与 `password`，成功后取得访问令牌。后续请求使用 `Authorization: Bearer <token>`。登录时检查账号是否启用及是否被删除；不要在日志或前端配置中保存明文密码。

新密码使用带随机盐的 PBKDF2 保存，兼容已有历史密码记录的校验。每次请求同时检查账号状态和 `token_version`，修改密码或启停账号后，旧令牌失效。当前登录令牌有效期为一小时。

普通账号按所属应用、知识库、私有模型及会话授权。公共模型可被选择，但不能被其他普通账号编辑；公开分享访客仅能访问相应聊天接口。认证和资源归属两层检查配合，避免仅隐藏前端菜单却仍能越权调用 API。

通过“系统 → 用户 → 创建用户”建立独立账号，详细流程与接口见[独立用户与资源权限](34.md)。
