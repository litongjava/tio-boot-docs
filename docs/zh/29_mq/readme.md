# 29_mq

本章介绍 MQTT 接入（Mica MQTT、EMQX）、进程内事件处理（Disruptor）以及 RocketMQ 的安装、整合与即时通讯实战。RocketMQ 整合由 tio-boot-admin 提供，不依赖 Spring。Disruptor 是进程内组件，与独立消息代理的部署方式不同。Kafka 与 AWS MSK 见 [30_kafka](../30_kafka/readme.md)。
