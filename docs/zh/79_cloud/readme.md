# 79_cloud

本章介绍用 tio-boot 构建微服务：以 Nacos 为注册中心和配置中心，服务启动后自动注册、关闭前自动下线，服务之间按服务名调用并负载均衡，客户端通过网关访问所有服务；网关转发 HTTP、SSE 流式响应和 WebSocket，路由和配置都可以在 Nacos 中修改后立即生效。所有能力都基于 tio-boot 原生 API，不依赖其他框架。

先按第一篇在本机启动 Nacos，再依次阅读注册发现、配置中心、服务调用和网关；最后两篇介绍这些能力用到的 tio-boot 底层功能，单独使用同样方便。
