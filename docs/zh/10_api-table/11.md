# ApiTable 联调与故障定位

先区分独立 ApiTable 与 tio-boot-admin 内置控制器，再对照同版本接口验证。

| 现象 | 检查点 |
| --- | --- |
| 404 | 控制器注册、上下文路径、是否被其他 Handler 接管 |
| 401 / 403 | 后台 Token 与操作授权，不通过放行全部表接口解决 |
| 表不存在 | 实际数据库、schema、大小写与手动建表情况 |
| 分页无效 | 接口是否使用 current/pageSize，响应是否正确映射 |
| 导出缺类 | EasyExcel 是否进入业务工程运行时依赖 |
| ID 改变 | BIGINT 是否被客户端转换成 Number |
| 编辑覆盖错误记录 | 主键及创建/更新接口是否正确 |
| 删除后仍返回 | 物理删除、逻辑删除和自定义查询条件是否一致 |

先做只读表配置和分页查询，再在独立测试表创建记录、保存主键、更新并重新查询，最后验证删除、恢复和导出。不要用生产业务表做随意写入测试。

复杂写入还需 [数据库集成测试](<../17_tests/03.md>)。具体接口见 [内置 ApiTable 路由](<../65_tio-boot-admin/03.md>)。
