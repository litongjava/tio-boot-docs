# DeepSeekClient 官方模型查询

```java
import nexus.io.deepseek.DeepSeekClient;
import nexus.io.tio.utils.environment.EnvUtils;

EnvUtils.load();
DeepSeekClient.getModels().getData()
    .forEach(model -> System.out.println(model.getId()));
```

该方法通过 `EnvUtils.get("DEEPSEEK_API_KEY")` 读取密钥，查询 DeepSeek 官方模型列表。开源仓库中的 `DeepSeek-OCR` 不等于官方 API 已开放同名模型。应先检查账号模型列表和官方协议；没有该模型时，不要自行猜测 OCR 端点，也不要将其他视觉模型的结果标成 DeepSeek-OCR。

Gitee 托管的 `DeepSeek-OCR` 使用 Gitee 密钥。`RustDeepseekOcrClient` 对应独立部署的 OCR 服务，也不是 DeepSeek 官方托管接口。

参考：[Gitee 接口文档](https://ai.gitee.com/docs/openapi/v1)、[DeepSeek 模型列表](https://api-docs.deepseek.com/api/list-models/)、[DeepSeek-OCR 官方仓库](https://github.com/deepseek-ai/DeepSeek-OCR)。

Gitee OCR 调用见 [GiteeClient](./18.md)，解析效果实测见 [知识库解析评测](../56_knowlege_base/28.md)。
