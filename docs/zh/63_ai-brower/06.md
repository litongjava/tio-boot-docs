# 启动浏览器

> 本文保留早期 Controller 多端点方案的教学示例；其中的接口地址、参数绑定和运行模型不适用于当前工程。当前开发请先阅读[统一命令接口与人机协作](./08.md)，完整命令参数以项目根目录的 SKILL.md 为准。

## HTTP 控制浏览器

本文档介绍如何通过 HTTP 接口启动、导航及关闭 Playwright 浏览器实例，并提供完整的示例代码

### 一、前置条件

1. 当前工程使用 Java 21 或以上环境
2. Playwright for Java 依赖
3. tio-boot 框架

### 二、核心数据结构：`BrowserInstance`

用于在内存中保存每个浏览器实例的上下文和页面引用。

```java
package nexus.io.ai.browser.service;

import java.nio.file.Path;
import java.util.ArrayList;
import java.util.Collections;
import java.util.IdentityHashMap;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;

import com.jfinal.kit.Kv;
import com.microsoft.playwright.BrowserContext;
import com.microsoft.playwright.BrowserType.LaunchPersistentContextOptions;
import com.microsoft.playwright.Page;
import com.microsoft.playwright.Playwright;
import com.microsoft.playwright.Request;

import nexus.io.ai.browser.dom.model.DOMState;

public class BrowserInstance {
  public final Playwright playwright;
  public BrowserContext context;
  public Page page;
  public Path profileDir;
  public LaunchPersistentContextOptions opts;
  /** 最近一次 get_dom_text 的 DOM 树快照,按索引操作元素时使用 */
  public DOMState domState;

  /** 最近一次弹窗信息 */
  public volatile Kv lastDialog;
  /** true 时自动取消弹窗,默认自动确认 */
  public volatile boolean dismissDialogs;

  /** 控制台日志与页面错误(最多保留 200 条) */
  public final List<String> consoleLogs = Collections.synchronizedList(new ArrayList<String>());
  public final List<String> pageErrors = Collections.synchronizedList(new ArrayList<String>());

  /** 网络请求记录(最多保留 200 条) */
  public final List<Kv> requests = Collections.synchronizedList(new ArrayList<Kv>());
  public final Map<Request, Kv> requestIndex = Collections.synchronizedMap(new IdentityHashMap<Request, Kv>());

  /** 已注册的路由规则:urlPattern -> {action, body, status, contentType} */
  public final Map<String, Kv> routes = new ConcurrentHashMap<>();
  public final Set<String> routedPatterns = ConcurrentHashMap.newKeySet();

  public BrowserInstance(Playwright playwright, BrowserContext ctx, Page pg, Path profileDir,
      LaunchPersistentContextOptions opts) {
    this.playwright = playwright;
    this.context = ctx;
    this.page = pg;
    this.profileDir = profileDir;
    this.opts = opts;
  }
}
```

`context`、`page` 是可变字段，切换标签页时直接替换 `page`，重启上下文时替换 `context` 与 `page`（源码里还有一个只接收 `playwright`、`context`、`page` 的 3 参数构造器）。`domState` 保存最近一次 `get_dom_text` 的 DOM 树快照，按索引接口优先使用它；`lastDialog`、`consoleLogs`、`pageErrors`、`requests`、`routes` 分别是弹窗、日志、网络记录与路由规则的状态容器。

### 三、服务层实现：`PlaywrightService`

负责启动、导航以及关闭浏览器实例，使用 `ConcurrentHashMap` 缓存所有活跃实例。

```java
package nexus.io.ai.browser.service;

import java.awt.Dimension;
import java.awt.Toolkit;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.Arrays;
import java.util.concurrent.ConcurrentHashMap;

import nexus.io.model.body.RespBodyVo;
import nexus.io.tio.utils.collect.Lists;
import nexus.io.tio.utils.snowflake.SnowflakeIdUtils;
import com.microsoft.playwright.BrowserContext;
import com.microsoft.playwright.BrowserType;
import com.microsoft.playwright.BrowserType.LaunchPersistentContextOptions;
import com.microsoft.playwright.Page;
import com.microsoft.playwright.Playwright;
import com.microsoft.playwright.Response;
import com.microsoft.playwright.options.RecordVideoSize;

public class PlaywrightService {

  // 存储所有浏览器实例
  private static final ConcurrentHashMap<Long, BrowserInstance> INSTANCES = new ConcurrentHashMap<>();

  /**
   * 启动或复用浏览器实例
   * @param id       可选：传入已有实例 ID 则复用该实例，否则自动生成新 ID
   * @param headless 是否以无头模式启动
   * @param record   是否录制视频
   * @return 浏览器实例 ID
   */
  public long start(Long id, boolean headless, boolean record) {
    Playwright pw = Playwright.create();
    // 持久化用户数据目录，cookie、LocalStorage 会保存在这里
    Path profileDir = Paths.get(System.getProperty("user.home"), ".config", "browseruse", "profiles", "default");
    Path downloadDir = Paths.get(System.getProperty("user.home"), "Downloads", "broswer");
    Path videosDir = Paths.get(System.getProperty("user.home"), "Videos", "broswer");

    LaunchPersistentContextOptions opts = new LaunchPersistentContextOptions().setHeadless(headless);
    opts.setIgnoreDefaultArgs(Lists.of("--enable-automation"));

    // 视口宽度按屏幕宽度计算，并追加常用启动参数
    Dimension screenSize = Toolkit.getDefaultToolkit().getScreenSize();
    int screenWidth = (screenSize.width / 32) * 28;
    int screenHeight = screenSize.height;
    boolean linux = System.getProperty("os.name", "").toLowerCase(java.util.Locale.ROOT).contains("linux");
    opts.setChromiumSandbox(!linux);
    opts.setArgs(linux ? Arrays.asList("--disable-dev-shm-usage") : java.util.Collections.emptyList());

    // 下载
    opts.setAcceptDownloads(true);
    opts.setDownloadsPath(downloadDir);

    // 录制
    if (record) {
      opts.setRecordVideoDir(videosDir);
      opts.setRecordVideoSize(new RecordVideoSize(screenWidth, screenHeight));
    }

    // 视窗与设备仿真：固定桌面 Chrome 的 User-Agent（常量定义在 consts.BrowserUserAgent）
    opts.setViewportSize(screenWidth, screenHeight);
    opts.setDeviceScaleFactor(1.0);
    opts.setIsMobile(false);
    opts.setHasTouch(false);

    // 权限
    opts.setPermissions(Arrays.asList("clipboard-read", "clipboard-write", "notifications"));

    BrowserContext ctx = pw.chromium().launchPersistentContext(profileDir, opts);

    // Playwright 会自动打开一个 about:blank 页，可以立刻拿到它
    Page firstPage = ctx.pages().get(0);
    // 屏蔽 navigator.webdriver
    firstPage.addInitScript("Object.defineProperty(navigator, 'webdriver', {get: () => false});");

    if (id == null) {
      id = SnowflakeIdUtils.id();
    }
    BrowserInstance instance = new BrowserInstance(pw, ctx, firstPage, profileDir, opts);
    // 挂载弹窗、控制台与网络监听
    attachListeners(instance, firstPage);
    attachRequestRecorder(instance);
    INSTANCES.put(id, instance);
    return id;
  }

  /**
   * 导航到指定 URL（复用同一个 Page 对象）
   * @param browserId 浏览器实例 ID
   * @param url       目标地址
   * @return Playwright Response 对象，可获取状态码、Headers 等
   */
  public Response navigate(Long browserId, String url) {
    BrowserInstance inst = INSTANCES.get(browserId);
    return inst.page.navigate(url);
  }

  /**
   * 关闭并移除浏览器实例
   * @param browserId 浏览器实例 ID
   * @return 操作结果
   */
  public RespBodyVo close(Long browserId) {
    BrowserInstance inst = INSTANCES.remove(browserId);
    if (inst != null && inst.context != null) {
      inst.context.close();
      inst.playwright.close();
      return RespBodyVo.ok();
    } else {
      return RespBodyVo.fail("没有找到对应的浏览器实例：" + browserId);
    }
  }
}
```

实例 ID 使用雪花 ID 生成，`start` 时传入 `id` 可以指定一个便于识别的固定 ID。`attachListeners` 为每个页面挂载弹窗、控制台日志与页面错误监听，`attachRequestRecorder` 在上下文上记录网络请求，两者都最多保留 200 条。

服务层还提供 `getDomText(Long browserId, Boolean highlight, Integer viewportExpansion)`：它调用 `DomService.getClickableElements(...)` 生成结构化文本，把结果缓存到实例的 `domState`（按索引接口的索引来源），并返回 `url`、`title`、`text`、`tabs`、`pixels_above`、`pixels_below`、`viewport_height`、`page_height`。

### 四、控制层实现：`PlaywrightController`

控制器通过 HTTP 接口暴露全部浏览器操作，当前共 79 个接口，都挂在 `/api/v1/playwright` 前缀下。下面是启动、导航和关闭三个接口，完整接口清单（导航、元素交互、信息读取、状态查询、定位方式、标签页、等待、鼠标、截图与 PDF、Cookie 与存储、浏览器设置、弹窗与控制台、网络、批量）见 [操作浏览器指令](<./07.md>)。

```java
package nexus.io.ai.browser.controller;

import com.jfinal.kit.Kv;
import nexus.io.ai.browser.service.PlaywrightService;
import nexus.io.annotation.RequestPath;
import nexus.io.jfinal.aop.Aop;
import nexus.io.model.body.RespBodyVo;
import com.microsoft.playwright.Response;

@RequestPath("/api/v1/playwright")
public class PlaywrightController {
  PlaywrightService playwrightService = Aop.get(PlaywrightService.class);

  /**
   * 启动或获取浏览器实例
   * 调用示例：GET /api/v1/playwright/start?id=&headless=true
   */
  @RequestPath("/start")
  public RespBodyVo start(Long id, boolean headless) {
    long newId = playwrightService.start(id, headless, false);
    return RespBodyVo.ok(Kv.by("id", newId));
  }

  /**
   * 导航到指定 URL
   * 调用示例：GET /api/v1/playwright/navigate?id=123&url=https://example.com
   */
  @RequestPath("/navigate")
  public RespBodyVo navigate(Long id, String url) {
    Response response = playwrightService.navigate(id, url);
    return RespBodyVo.ok(Kv.by("status", response.status()));
  }

  /**
   * 关闭浏览器实例
   * 调用示例：GET /api/v1/playwright/close?id=123
   */
  @RequestPath("/close")
  public RespBodyVo close(Long id) {
    return playwrightService.close(id);
  }
}
```

启动入口是 `nexus.io.ai.browser.PlaywrightApp`，它在 `main` 中把配置类 `nexus.io.ai.browser.config.PlaywrightAppConfig` 交给框架，由配置类注册控制器：

```java
package nexus.io.ai.browser;

import nexus.io.ai.browser.config.PlaywrightAppConfig;

import nexus.io.tio.boot.TioApplication;

public class PlaywrightApp {

  public static void main(String[] args) {
    TioApplication.run(PlaywrightApp.class, new PlaywrightAppConfig(), args);
  }
}
```

```java
package nexus.io.ai.browser.config;

import java.util.ArrayList;
import java.util.List;

import nexus.io.context.BootConfiguration;
import nexus.io.tio.boot.http.handler.controller.TioBootHttpControllerRouter;
import nexus.io.tio.boot.server.TioBootServer;

public class PlaywrightAppConfig implements BootConfiguration {

  @Override
  public void config() {
    TioBootHttpControllerRouter controllerRouter = TioBootServer.me().getControllerRouter();
    if (controllerRouter != null) {
      List<Class<?>> scannedClasses = new ArrayList<>();
      scannedClasses.add(nexus.io.ai.browser.controller.PlaywrightController.class);
      controllerRouter.addControllers(scannedClasses);
    }
  }

```

源码包名统一为 `nexus.io.ai.browser`，控制器在 `nexus.io.ai.browser.controller`，服务与实例模型在 `nexus.io.ai.browser.service`，DOM 模型与解析在 `nexus.io.ai.browser.dom.model`、`nexus.io.ai.browser.dom.service`，配置在 `nexus.io.ai.browser.config`；测试类分布在 `nexus.io.ai.browser.demo`、`nexus.io.ai.browser.util`、`nexus.io.ai.browser.service`、`nexus.io.ai.browser.dom.service` 下。

### 五、使用示例

示例端口取自 `app.properties` 中的 `server.port`，本文档使用 `10049`。

**统一响应体**

所有接口都返回同一个结构：

```json
{"data":{},"code":1,"ok":true,"error":null,"msg":null}
```

成功时 `code` 为 `1`、`ok` 为 `true`，`error` 与 `msg` 为 `null`；失败时 `code` 为 `0`、`ok` 为 `false`，`msg` 是中文失败原因，例如 `没有找到对应的浏览器实例：1234567890123456`。未捕获异常（例如缺少必需参数触发空指针）不经过响应体包装，直接返回裸 HTTP 500。`id` 是 Long 型雪花 ID，序列化成字符串。

**参数绑定**

除 `execute_js` 与 `commands` 外，控制器里的方法都是老式多参数方法，参数只从 query 或表单（`application/x-www-form-urlencoded`）读取，**JSON 请求体不生效**，因此下面所有示例都用 query 传参；缺少必需参数时会触发空指针并返回 HTTP 500。`execute_js` 走 `HttpRequest.getRequestMap()`，query、表单、JSON 请求体三种方式都支持；`commands` 是唯一的例外，它**必须用 POST + JSON 请求体**，不接受 GET、表单，也没有 `bodyJson` 参数。

1. **启动浏览器（无头模式）**

   ```
   GET http://localhost:10049/api/v1/playwright/start?headless=true
   ```

   响应：

   ```json
   {
     "data": { "id": "1234567890123456" },
     "code": 1,
     "ok": true,
     "error": null,
     "msg": null
   }
   ```

   返回值中的 `id` 就是后续所有接口要传的浏览器实例 ID，`start` 时也可以传入自己指定的 `id` 复用实例。后续示例只保留 `data` 与 `code` 字段。

2. **导航到页面**

   ```
   GET http://localhost:10049/api/v1/playwright/navigate?id=1234567890123456&url=https://www.taobao.com
   ```

   响应：

   ```json
   {
     "data": { "status": 200 },
     "code": 1
   }
   ```

3. **获取页面结构化文本与元素索引**

   ```
   GET http://localhost:10049/api/v1/playwright/get_dom_text?id=1234567890123456
   ```

   响应中的 `data.text` 每行形如 `[index]<tag attr='value'>文本/>`，`index` 就是按索引接口要用的元素索引；该次快照会被缓存，页面变化后需要重新调用。

4. **关闭浏览器实例**

   ```
   GET http://localhost:10049/api/v1/playwright/close?id=1234567890123456
   ```

   响应：

   ```json
   {
     "data": {},
     "code": 1
   }
   ```

### 六、在页面中执行 JavaScript

除固定指令外，控制器提供 `/execute_js`，由客户端提交 `id` 与 `body`（JavaScript 代码），在浏览器当前页面执行并返回结果。

```
POST /api/v1/playwright/execute_js
{ "id": 1234567890123456, "body": "document.title" }
```

响应：

```json
{
  "code": 1,
  "data": { "result": "百度一下，你就知道" }
}
```

`id` 和 `body` 既可以放在 JSON 请求体中，也可以放在查询参数或表单参数中，同名参数以 JSON 请求体为准。控制器里只有 `execute_js` 读取 `HttpRequest.getRequestMap()`；`commands` 必须用 POST + JSON 请求体（见下文批量指令）；其它接口的参数只从 query 或表单读取，JSON 请求体不生效。校验失败时返回 `code` 为 0，`msg` 给出原因，例如 `id is required`、`id must be an integer`、`body is required`、`Invalid JSON`。

`body` 支持三种写法，都会按客户端提交的形式直接求值：

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 表达式 | `document.title` | 返回表达式的值 |
| 函数 | `() => document.title`、`() => { return document.title; }` | 求值结果是函数时会被自动调用 |
| 语句片段 | `const el = document.querySelector('#kw'); return el.value;` | 含 `return` 的片段会被包装成函数体后执行 |

返回值需要是 JSON 可序列化的值，字符串、数字、布尔、数组、普通对象都可以直接返回；DOM 元素不会报错，但只会得到 `ref: <Node>` 这样的引用，请先转换为 `outerHTML`、`textContent`、`value` 等基本类型。脚本报错时返回失败响应，`msg` 只保留异常的第一行，例如 `执行 JavaScript 失败：TypeError: Cannot read properties of null (reading 'click')`。

浏览器实例不存在时返回 `没有找到对应的浏览器实例：<id>`。脚本长度上限为 100000 个字符。

`execute_js` 也可以作为批量指令中的一项。批量接口是 `/api/v1/playwright/commands`，除 `commands` 自身之外的 78 个接口都能作为命令调用，命令名就是接口路径去掉斜杠，每一步的结果都在 `data.results` 里原样返回。该接口只接受 `POST` + JSON 请求体，请求体可以直接是对象载荷、命令数组，也可以只写一条命令：

```shell
curl -s -X POST -H 'Content-Type: application/json' \
  -d '{"id":1234567890123456,"stopOnError":false,"commands":[{"execute_js":{"body":"document.title"}},{"get_dom_text":{}}]}' \
  "http://localhost:10049/api/v1/playwright/commands"
```

如果请求体直接是命令数组 `[{"命令名":{参数}}, ...]`，则必须把 `id` 放在查询串里（`?id=...`）；GET、表单与 `bodyJson` 字段都不再支持（GET 会返回 `批量指令只支持 POST + JSON 请求体,请用 POST 并把命令放在请求体里`）。

完整的请求写法、逐步结果与 PTC 用法见 [操作浏览器指令](<./07.md>) 的“批量”一节。

### 七、注意事项

* `LaunchPersistentContextOptions` 会在用户目录下的 `~/.config/browseruse/profiles/default` 中保存浏览器数据，如 cookies、LocalStorage 等；如需每次全新上下文，可改用 `browser.newContext()`。
* `SnowflakeIdUtils` 仅为示例 ID 生成方式，您可替换为任意唯一 ID 方案。
* `/execute_js` 会执行客户端提交的任意脚本，部署到公网前需要自行增加鉴权与访问控制。
* Playwright 的 `evaluate` 不设超时，脚本中不要写死循环或长时间等待，否则请求会一直挂起。
