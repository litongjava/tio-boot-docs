# AI Browser：使用指南与源码教程

本系列面向 deepseek-browser-use 的使用者和开发者。当前服务通过统一的 `POST /playwright/command` 接收命令。示例使用虚构 ID、域名和资料；运行结果与截图仍需按业务要求脱敏。

初学者可按 01 → 02 → 03 → 04 → 06 的顺序，理解总体架构、模型决策、前端 DOM、Java DOM 模型和 HTTP 控制流程。05 讲内容抽取扩展，07 为 Controller 示例提供配套接口参考。原文和完整代码保留；涉及现行服务差异的地方在篇首说明。
