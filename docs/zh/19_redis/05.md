# 使用 Jedis 连接池接入 Redis

Jedis 是 Redis 的 Java 客户端。本章 java-db 示例使用 Jedis 4.3.1。直接使用 Jedis 时，应共享 JedisPool，每次操作从池中借出连接并在结束后归还。

## 依赖

```xml
<dependency>
  <groupId>redis.clients</groupId>
  <artifactId>jedis</artifactId>
  <version>4.3.1</version>
</dependency>
```

## 最小示例

```java
import redis.clients.jedis.Jedis;
import redis.clients.jedis.JedisPool;

public class JedisPoolExample {
  public static void main(String[] args) {
    try (JedisPool pool = new JedisPool("127.0.0.1", 6379)) {
      try (Jedis jedis = pool.getResource()) {
        jedis.setex("demo:jedis:hello", 60L, "hello");
        System.out.println(jedis.get("demo:jedis:hello"));
      }
    }
  }
}
```

本例假设本地 Redis 无认证。Web 项目应在应用初始化时创建连接池、请求中借用连接、应用关闭时销毁池；不要将单个 Jedis 连接作为所有请求共享的 Bean。认证、超时、TLS 与池容量应根据部署环境配置。

已有 java-db 的项目可以使用 [RedisPlugin 与 Redis.call](./01.md) 管理连接池生命周期。两种方式按项目需求选择，避免无意中创建多个同用途的连接池。
