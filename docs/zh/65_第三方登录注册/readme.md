# 65_第三方登录注册

本章按邮件、短信和第三方身份提供方组织登录、注册及账号找回流程。基础 Token 与权限管理见[认证](<../13_认证/readme.md>)；邮件服务等通用接入见[第三方集成](<../24_integration_thirty_party/readme.md>)。

## 验证类型

`verification_type` 表示验证方式，不局限于邮箱验证。

| 值 | 验证方式 |
| --- | --- |
| `0` | 不验证 |
| `1` | 邮箱验证码验证 |
| `2` | 邮箱链接验证 |
| `3` | 短信验证码验证 |

短信服务商由后端配置决定，腾讯云和阿里云使用相同的短信验证类型，不为每个服务商分配不同的值。后续新增方式时统一扩展此表；未支持的值必须拒绝，不能按 `0` 处理。

具体接口应明确允许的验证类型，并由后端业务策略决定是否允许 `0`，不能让客户端通过选择“不验证”绕过必需的验证。发送验证码或验证链接不代表验证完成，只有后端核验通过才能更新对应的邮箱或手机号验证状态。
