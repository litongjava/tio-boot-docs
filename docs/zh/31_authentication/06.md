### 3.3 服务层实现

**`AppUserService.java` 用户与密码方法**

下面只列出与用户表、密码有关的方法，完整类以框架源码为准。密码的盐与哈希规则由同一组静态方法提供，注册、修改密码、登录校验都调用它们。

```java
import java.security.SecureRandom;
import java.util.HexFormat;

import org.apache.commons.codec.digest.DigestUtils;

import nexus.io.db.activerecord.Db;
import nexus.io.db.activerecord.Row;
import nexus.io.model.body.RespBodyVo;
import nexus.io.tio.boot.admin.sql.AppUsersSql;
import nexus.io.tio.boot.admin.vo.AppUser;
import nexus.io.tio.boot.admin.vo.UserUpdatePasswordRequest;

public class AppUserService {
  // 查询用户基本信息，不含密码相关字段
  private static final String SQL_SELECT_USER = AppUsersSql.findById;
  // 只查询密码盐与哈希，已删除用户查不到
  private static final String SQL_SELECT_PASSWORD = "SELECT id, password_salt, password_hash FROM app_users WHERE id = ? AND deleted = 0";
  private static final SecureRandom PASSWORD_SALT_RANDOM = new SecureRandom();

  // 生成 16 字节随机盐，十六进制表示
  public static String createPasswordSalt() {
    byte[] bytes = new byte[16];
    PASSWORD_SALT_RANDOM.nextBytes(bytes);
    return HexFormat.of().formatHex(bytes);
  }

  // 哈希规则：sha256(密码 + 盐)，注册、修改密码、登录校验共用
  public static String hashPassword(String password, String salt) {
    return DigestUtils.sha256Hex(password + salt);
  }

  public AppUser getUserById(String userId) {
    return Db.findFirst(AppUser.class, SQL_SELECT_USER, userId);
  }

  public AppUser getUserPasswordById(String userId) {
    return Db.findFirst(AppUser.class, SQL_SELECT_PASSWORD, userId);
  }

  // 空输入直接返回 false，避免 null 参与拼接后误判
  public boolean verifyPassword(AppUser user, String password) {
    if (user == null || password == null || user.getPasswordHash() == null) {
      return false;
    }
    return hashPassword(password, user.getPasswordSalt()).equals(user.getPasswordHash());
  }

  // 每次设置密码都生成新盐，盐与哈希在同一条 UPDATE 中写入
  public boolean setPassword(String userId, String password) {
    String salt = createPasswordSalt();
    String sql = "UPDATE app_users SET password_salt = ?, password_hash = ? WHERE id = ? AND deleted = 0";
    return Db.updateBySql(sql, salt, hashPassword(password, salt), userId) == 1;
  }

  // 先校验旧密码，通过后用 setPassword 写入新密码
  public RespBodyVo updatePassword(String userId, UserUpdatePasswordRequest request) {
    AppUser user = getUserPasswordById(userId);
    if (user == null || !verifyPassword(user, request.getOldPassword())) {
      return RespBodyVo.fail();
    }
    int effected = setPassword(userId, request.getNewPassword()) ? 1 : 0;
    return RespBodyVo.ok(effected);
  }

  // 按字段更新用户。Row 中的 password_salt、password_hash 不会被移除，调用方需要自行过滤
  public boolean updateById(String userId, Row row) {
    row.set("id", userId);
    return Db.update("app_users", row);
  }
}
```

注册接口（`registerUser`、`registerUserByUserId`）同样使用 `createPasswordSalt()` 与 `hashPassword()`，因此注册后的账号可以直接用 `verifyPassword` 登录。调用 `setPassword` 或 `updatePassword` 成功后，旧盐和旧哈希一并被替换，新密码立即生效。

### 3.4 控制器实现

**`AppUserHandler.java` 请求处理**
```java
public class AppUserHandler {
  
  // 获取用户信息
  public HttpResponse profile(HttpRequest request) {
    String userId = TioRequestContext.getUserIdString();
    AppUser user = Aop.get(AppUserService.class).getUserById(userId);
    return TioRequestContext.getResponse().body(RespBodyVo.ok(user));
  }

  // 更新用户信息
  public HttpResponse update(HttpRequest request) {
    String userId = TioRequestContext.getUserIdString();
    Map<String, Object> params = FastJson2Utils.parseToMap(
        request.getBodyString(), 
        String.class, 
        Object.class
    );
    return TioRequestContext.getResponse().body(
        RespBodyVo.ok(Aop.get(AppUserService.class).updateById(userId, Row.fromMap(params)))
    );
  }

  // 更新密码
  public HttpResponse updatePassword(HttpRequest request) {
    String userId = TioRequestContext.getUserIdString();
    UserUpdatePasswordRequest req = FastJson2Utils.parse(
        request.getBodyString(), 
        UserUpdatePasswordRequest.class
    );
    RespBodyVo result = Aop.get(AppUserService.class).updatePassword(userId, req);
    return TioRequestContext.getResponse().body(result);
  }
}
```

## 4. 安全注意事项

1. **敏感字段过滤**：
   - 更新接口中需显式移除 `password_salt` 和 `password_hash` 字段
   - 查询接口不应返回密码相关字段

2. **密码安全**：
   - 使用 SHA-256 加盐哈希存储密码
   - 密码更新需验证原始密码
   - 前端传输应使用 HTTPS 加密

3. **权限控制**：
   - 所有接口需通过 JWT 认证
   - 用户只能操作自己的数据（通过 `TioRequestContext.getUserIdString()` 获取当前用户）
